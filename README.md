# 📝 To-Do List Website

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript. This project helps users manage their daily tasks by allowing them to add tasks dynamically.

## 🚀 Features

- Add new tasks
- Prevent empty task entries
- Simple and user-friendly interface
- Responsive design
- Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
